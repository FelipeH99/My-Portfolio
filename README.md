# My-Portfolio · Experimento con Next.js

Repositorio de exploración de Next.js 14, React y TypeScript. Conserva la pantalla inicial de `create-next-app` y sirve como base de aprendizaje del App Router.

**El portfolio vigente está en [felipeheredia.vercel.app](https://felipeheredia.vercel.app).** Este repositorio no contiene la versión publicada de mi perfil profesional.

## Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS

## Ejecución local

```sh
git clone https://github.com/FelipeH99/My-Portfolio.git
cd My-Portfolio
npm ci
npm run dev
```

Abrí `http://localhost:3000`. La página inicial está en `src/app/page.tsx` y el layout en `src/app/layout.tsx`.
